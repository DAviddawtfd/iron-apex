# IRON APEX — как получить APK и поставить на телефон

## Шаг 1. Собрать APK (любой вариант)

**A. GitHub Actions (не нужно ничего устанавливать)**
1. Загрузи проект в репозиторий GitHub (`git push`).
2. Вкладка **Actions** → **Build Android APK** → **Run workflow** (или он запустится сам после push).
3. Через ~5–7 минут открой завершённый запуск → блок **Artifacts** → скачай `IRON-APEX-apk` (zip с `IRON-APEX.apk`).

**B. Локально (нужны JDK 17+ и Android SDK — проще всего поставить Android Studio)**
- Windows: двойной клик по `build-apk.bat`
- macOS / Linux: `./build-apk.sh`

Готовый `IRON-APEX.apk` появится в корне проекта.

## Шаг 2. Перенести APK на смартфон
Через USB-кабель, Telegram «Избранное», Google Drive или почту — любым способом, чтобы файл оказался в «Загрузках» телефона.

## Шаг 3. Установить и выдать разрешения
1. Открой `IRON-APEX.apk` на телефоне → Android попросит разрешить установку из этого источника (Chrome / Файлы / Telegram) → **Разрешить** → **Установить**.
2. Google Play Protect может предупредить о неизвестном разработчике — **Всё равно установить** (это debug-сборка без подписи магазина).
3. При первом старте тренировки разреши **уведомления**. На Android 12+ в «Профиле» появится карточка **«Разреши точные будильники»** — нажми её, чтобы сигнал отдыха приходил секунда в секунду при выключенном экране.

> Данные хранятся только на телефоне. Перед переустановкой/сменой телефона: «Профиль» → **Экспорт** (JSON), после — **Импорт**.
